# Reflection

I used Codex as a planning, implementation, testing, and review partner during this sprint. I first asked it to inspect the existing FastAPI models, in-memory store, routes, frontend, and tests before suggesting changes. That context mattered: both features could be implemented by extending the current model and list endpoint instead of introducing a database or a new service layer. I then used focused prompts for each backend slice, its tests, and the matching frontend behavior. Finally, I used the browser automation capability to exercise the UI rather than treating passing API tests as proof that the visible feature worked.

AI helped most when it exposed a design issue in overdue handling. A simple implementation could label every past date overdue, including completed tasks, or persist an `is_overdue` boolean that becomes wrong the next day. Reviewing that suggestion led me to define overdue precisely as “due before today and not Done” and calculate it at request/render time. The resulting tests use yesterday and tomorrow rather than fixed historical dates, so they remain meaningful.

AI slowed me down when browser automation selected the form's Priority control ambiguously because the page also has a “Filter by priority” control. The first interaction failed and I had to inspect the evidence, use the exact accessible label, and continue from the actual page state. A later wait also timed out after a successful edit because the edited task correctly disappeared from the active overdue filter. Those moments reinforced that an automation error is not automatically an application error.

My review changed the result in two important places. I constrained search to title and description instead of silently including assignee, keeping the public contract aligned with the brief. I also changed browser overdue comparison to a local calendar-date string, avoiding UTC midnight boundary bugs. The deliberate Break Tests confirmed that the new tests fail when overdue expectations or search inputs are wrong. Overall, AI accelerated implementation, but evidence from tests, rendered UI state, and browser logs determined what I accepted.
